## Blockers / Risks

- [ ] The production preprocessing is tuned for white, evenly lit PDF-rendered pages. Validate it against new scan sources before enabling it universally.
- [ ] Structure-analysis accuracy is unknown because no labeled ground truth is currently available.
- [ ] The available pretrained FUNSD label set is incompatible with the relay-form schema and is useful only for pipeline smoke testing.
- [ ] Current OCR supplies block-level polygons; word bboxes are proportional approximations until OCR emits true word-level boxes.
- [ ] Record grouping may fail where columns shift, OCR merges/splits blocks, or a value belongs to a visually distant field; human review or labeled evaluation remains required.
- [ ] Some scans have faint/missing table rules and some OCR blocks span two detected cells. Those cases need cell-level OCR or human review; grid geometry alone cannot recreate characters that OCR omitted.
